## Scope Guardrails

- Do not batch-change title, H1, URL, canonical, robots, sitemap inclusion, 301 redirects, or noindex for top Naver performers without operator approval.
- Do not run Google recovery work such as 301, noindex, or page merging in this PR.
- Do not change existing AdFit slot positions, counts, environment variables, or render conditions.
- Do not serve different SEO content to Googlebot, Naver Yeti, and regular users.

## Technology Structure

| Item | Current state |
|---|---|
| Spring Boot | 3.5.14 |
| Java | 17 |
| View layer | Thymeleaf via `spring-boot-starter-thymeleaf` |
| Public route registry | `SitePages.ALL` plus controller `@GetMapping` methods |
| Common layout | Per-template shell with shared `fragments/head`, `fragments/nav`, `fragments/components`, `fragments/footer` |
| title source | `PageInfo.title()` mapped to model attribute `pageTitle` |
| description source | `PageInfo.description()` mapped to model attribute `pageDescription` |
| canonical source | `PublicUrlService.absoluteUrl(page.path())`, rendered in `fragments/head` |
| Open Graph source | `og:title` and `og:description` mirror page title/description; `og:image` currently uses shared `/og-image.png` |
| robots | Shared `index, follow, max-snippet:-1, max-image-preview:large, max-video-preview:-1` meta tags |
| Structured data | `SeoService` emits Organization, WebSite, WebPage, WebApplication, Article, BreadcrumbList, FAQPage |
| sitemap.xml | `SeoController.sitemap()` from `SitePages.sitemap()` |
| rss.xml | `SeoController.rss()` from `SitePages.sitemap()` |
| robots.txt | `SeoController.robots()`, allows all and points to `/sitemap.xml` |
| Analytics | No existing GA4/gtag-specific event layer found before this PR |
| AdFit | `app.adfit.*` properties, `AdFitViewModel`, `fragments/adfit`, and footer SDK mount script |

## Analytics Event Plan

The frontend event layer sends only route-level properties and never sends raw salary, loan, tax, investment, usage, or other numeric input values.

| Event | Trigger |
|---|---|
| `organic_landing_view` | Initial page load when `document.referrer` is classified as organic search |
| `calculator_start` | Calculator form submit |
| `calculator_complete` | Result panel is shown after SSR or client-side calculation |
| `result_view` | Result panel is shown after SSR or client-side calculation |
| `quick_preset_click` | Future-compatible handler for elements with `data-quick-preset` |
| `comparison_table_view` | First viewport exposure of a comparison/data table |
| `related_calculator_click` | Click on related calculator links |
| `official_source_click` | Click on official source links |

Required properties emitted by the event layer:

| Property | Source |
|---|---|
| `page_path` | `window.location.pathname` |
| `calculator_type` | route-to-calculator mapping |
| `content_cluster` | route-to-cluster mapping |
| `device` | viewport width, `mobile` at 820px or below |
| `referrer_host` | parsed `document.referrer` host |
| `referrer_type` | `naver_organic`, `google_organic`, `search_organic`, `internal`, or `external` |
| `experiment_variant` | `document.documentElement.dataset.experimentVariant`, default `control` |
