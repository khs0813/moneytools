## Audit Findings

| Check | Pre-change result | Current mitigation in this branch |
| --- | --- | --- |
| Mobile/PC branching | One Thymeleaf slot contains desktop and mobile env values; footer JS selects one viewport unit. | Preserved. Only one `ins.kakao_ad_area` is mounted. |
| Same DAN ID duplicate use | Guide placements share `PUBLIC_ADFIT_GUIDE_DESKTOP/MOBILE`. | Existing unit-key guard prevents duplicate initialization on the same path. |
| Hidden ad request | The generated `ins.kakao_ad_area` used `display:none`. | Changed to visible block sizing before request. Deferred post-tool placeholders are hidden only before request. |
| Recalculate/reselect re-request | In-memory guard did not survive server-rendered POST reloads. | Path+placement is persisted in `sessionStorage`; DAN ID is not stored. |
| SDK duplicate load | Footer checks for existing SDK script. | Preserved and strengthened with `state.sdkRequested`. |
| CLS reservation | CSS reserves `300x250`, `728x90`, and `320x100` frame heights. | Preserved; hidden deferred slots reserve no space before result. |
| `onfail` handling | No explicit failure handling. | Added render timeout failure event and slot removal. |
| Missing env values | Local defaults are empty strings. Render values unavailable here. | Empty env still removes the slot and makes no ad request. |
| Recently missing ad units | Cannot verify from Render in this workspace. | Provided metrics mark guide/home desktop and home mobile as OFF candidates, not immediate deletions. |

## First Experiment Candidate
